## Project Overview

A language-learning web app built with **React 19**, **React Router v7** (SSR enabled), **TailwindCSS v4**, and **TypeScript**. Users learn vocabulary via flashcard-style questions across categories and levels. Production domain: `learn-language.es`.

## Commands

```bash
npm run dev          # Start dev server (port 5174) — runs orval typegen first
npm run build        # Production build
npm run start        # Serve production build
npm run typecheck    # react-router typegen + tsc
npm run typegen      # Regenerate API types from OpenAPI (backend must run at localhost:8000)
npm run i18n:sync    # Translate i18n keys via OpenAI (requires OPENAI_API_KEY)
npx eslint .         # Lint
npx prettier --write . # Format
```

No test framework is configured.

## Architecture

### SSR + Routing

React Router v7 with `ssr: true`. Routes defined in `app/routes.ts`. The root loader (`root.tsx`) fetches the current user and i18n messages server-side.

Routes: `/` (home), `/statistics`, `/settings`, `/category/:id`, `/category/:id/questions`.

### Feature-Sliced Design (FSD)

```
app/
├── shared/      # Base UI components, hooks, stores, utils (no business logic)
├── entities/    # Domain model display components (CategoryCard, etc.)
├── features/    # User-facing features (IssueForm, etc.)
├── routes/      # Page components with route-private sub-components in components/
└── widgets/     # (currently empty)
```

### State Management

- **TanStack React Query v5** — all server state. Hooks are auto-generated by Orval.
- **Zustand v5** — client state (notification store only).
- Local `useState` for UI-only state.

### API Layer

**Orval** generates React Query hooks + Zod schemas from two OpenAPI specs:
- Client API: `app/types/client-api.ts`
- Auth API: `app/types/auth-api.ts`

**Never edit files in `app/types/`** — regenerate with `npm run typegen` (requires backend at `localhost:8000`).

Axios instances (`clientAxios`, `authAxios`) in `app/shared/lib/apiClient/apiClient.ts` handle requests. 401 responses trigger redirect to `/admin/login`.

### i18n

Custom-built (no external library). Supported locales: `en`, `ru`, `es`, `fr`, `it`.

- **Only edit `i18n/en.json`** — other locale files are auto-generated by CI via OpenAI GPT-4o-mini.
- Translation JSON served from Cloudflare R2 CDN. Root SSR loader fetches the appropriate locale.
- Language detection: cookie → user profile API → default `en`.
- Usage: `const { t } = useI18n("page.home"); t("title")` looks up `messages.page.home.title`.

### Forms

react-hook-form + zod + @hookform/resolvers. Custom `Form` component wraps `FormProvider`.

## Key Conventions

- **Imports**: Use `~/` alias for all `app/` imports (e.g., `import { Button } from "~/shared/components"`).
- **Tailwind classes**: When 8+ classes, group with `clsx(...)`. Custom ESLint plugin (`tw-classname-group/prefer-cn`) enforces this with auto-fix. Use `cn()` from `~/shared/lib/utils` when merging is needed.
- **Notifications**: `useNotificationStore()` from `~/shared/stores` — `.success()`, `.error()`, `.warning()`, `.info()`, `.custom()`. Special types `"level-up"` and `"category-finished"` render animated notifications.
- **FSD file placement**: Утилиты, константы, хелперы и прочий код размещать строго по FSD. `shared/` — только базовый код без бизнес-логики. Код с бизнес-логикой, специфичный для страницы, кладётся в `routes/<route>/utils/`. В `shared/utils/` — только то, что реально переиспользуется между несколькими роутами.
- **Extract logic immediately**: Вычислительную логику сразу выносить в утилиту, не инлайнить в компонент.
- **null vs undefined**: `null` — когда отсутствие значения присваивается намеренно (например, "результат не найден"). `undefined` — когда значение не определено или не инициализировано.
